# 策略与字段口径

## 漏斗（v10）

1. 剔除 ST/风险警示（`stock_st`，失败回退名称含 ST）
2. 申万一级行业白名单：银行、非银金融、公用事业、交通运输、煤炭、钢铁、
   石油石化、家用电器、通信、建筑装饰、纺织服装（映射纺织服饰）、食品饮料
3. 分红年数 ≥ 2（近 5 年，已实施且除权除息日 ≤ 截止日）
4. 六道关：
   - 扣非净利润为正的年数 ≥ 3（近 5 年年报）
   - 经营现金流 / 分红总额 ≥ 0.5
   - 当前股息率（近三年平均 DPS / 现价）在 4%~8%
5. 资产负债率 ≤ 70%（最新已公告报告期）
6. PB ≤ 1.5 且 5 年 PB 百分位 ≤ 30%

## 锚定价

- `est_annual_dps` = 近三年平均每股分红
- `P_min` = est_dps / (无风险利率 2.7% × 1.3)
- `P_avg` = est_dps / 历史平均股息率
- 历史平均股息率 > 3.51% 时 `P_avg < P_min` 属公式特性

## 次日最低价 lx

用前一交易日 1 分钟线：最高价之后的放量分钟最低价 / 当日最高价 × 收盘价；
`next_P_min = min(lc, ld, lx)`，`next_P_avg = mean(lc, ld, lx)`。

## 数据口径

- 价格不复权（`daily` / `stk_mins` 原生不复权）
- 分红金额 = 每股税前分红 × 年末总股本（万股）× 10000
- 财务只用到截止日已公告（`ann_date <= 截止日`）的报告
